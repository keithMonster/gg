# 需求拷问触发形态：归因 L3b 帧层 + 解 = 欠定点空槽（样板杠杆），否决默认讨论态

## 给父会话的最终输出

### 开题四问产物

- **① 重写问题**：原表述「该不该默认进讨论态」是假二选一。重写：**「需求欠定性」这个认知产物该在哪里被强制生产出来**——它不显形，monster 已有的 Decision Authority（目标层归 Keith）就是一条没有输入的规则。
- **② 判据先行**：裁「加机制」算错，若 6 个月后该槽像 cg-platform 阶段声明一样 0/N 实填或恒填套话「欠定点：无」；现形物理量 = 承重产物中该槽的实填率（可 grep，天然 tripwire 靶）。
- **③ 补集采样**：全量讨论态默认 / 什么都不做（纯 Keith 兜底）/ UserPromptSubmit 注入器——三条均在正文逐一否决，理由见裁决。
- **④ 最便宜一击**：本轮召唤材料已含父会话核实过的物理证据（47 条分层失败样本、16 个月零使用率、注入器 0 效两例、PRD 骨架 7/9 实填）；gg 侧对账 08-14 stage-retirement 判例（登记处 vs 住所同构）。

### 裁决一：归因 —— L3b 帧层召回失效（帧变体），带不可收的 L4 残余；不是 L2，不是 L3a

两组「矛盾」证据不矛盾，它们分属两层：

- 6 条「先问一句就不会发生」→ **L3b 的帧变体**：模型不是不想问（非 L3a 动机对抗），是「这个需求可能欠定」这个问题在产出帧的语法里**根本提不出来**（对齐 monster CLAUDE.md:147 既有裁定「帧问题非阈值问题」+ gg essence `frame-grammar`：任务帧约束可被提问的问题，激活帧外认知必须换帧、不是加提醒）。
- 4 条「问了也没用 / 不可工程化预防」→ **L4 残余**：单轮语音输入的欠定性是信息论事实，复杂需求需要多轮是本质不是缺陷。任何机制都收不掉这部分，明说不收。
- 关键消歧：**标准 L3b 解（注入器）在这里也是弱解**——注入器治「内容不在视野」，本病是「帧不接受这个动作」：注入的提醒进入产出帧后被帧语法消化（两例实证：writing_readers_inject 满勤注入同日仍错 3 次；coding_reminder 第 6 条满勤 4 周 0 次跑通）。换帧的有效机制 monster 自己已有实证：意图回显有效恰因「出方案」这个强制动作换了帧。
- 2026-08-05 提案把它当 L2 解（加一条「默认讨论态」prompt 规则）——正是 monster 自己点名的最高频误判（把 L3 当 L2 解）。

### 裁决二：触发形态 —— 否决三个候选，解是第四条：欠定点空槽住进承重产物骨架

**否决 (b) 默认讨论态**（= 2026-08-05 提案形态否决）：① 它是姿态规则，属「保持怀疑」软 prompt 族——外部实测无效（essence `falsification-as-structure-not-just-skepticism`：软怀疑无效，有效的是结构动作）；② 与 Keith 画像正面冲突（异步过决策点、不弹问卷、通勤语音输入最烦被同步盘问）；③ 需求首述 ~每月 9 次中多数「直接做」是对的，默认讨论态把高频正确行为换成低频正确行为，存在税（占 Keith 注意力）远超收益；④「进入讨论态」要求判定「这是需求首述」——语义判定 + 用户侧元动作，正是 08-14 判例证死的形态（要求元动作的机制 0/25 存活）。

**否决 (c) 注入器 hook**：见裁决一，帧病注入弱效，两例实证。

**否决 (a′) 纯维持现状**：兜底成本已被量化——7 条真实返工留痕 + 单轮 26 万 token 自证 + 约每月 2 次失败频率；Keith 把决定权下放本身就是「在场兜底不够」的信号。

**裁定形态（d）**：把「意图回显」从镜像动作升级为结构动作——**承重产物（方案 / brief / 诊断报告）的骨架里加一个空槽：「欠定点 1–3 条 + 每条我拍的默认值」**，并按既有 Decision Authority 分流：落实现层的自拍默认值（Keith 异步扫一眼，对则零成本通过）、落目标层 / 偏好 / 不可逆的出选择题抛回。要点：

1. **载体选样板不选规则**，由约束 4 直接锁定（PRD 空槽 7/9 实填 vs 读文档照做 0%）；与 08-14 判例同构——活机制住在骨架空槽，死机制要求主动元动作。
2. **空槽是结构动作不是姿态**：填不出 = 没做（field-gravity / reverse-anchor）；「欠定点：无」合法但须写「本需求完备因为 X」。它与「复述式意图回显」的差别 = falsification 实测里有效 / 无效两族的差别——这是本裁决押的核心区分。
3. **它是分诊器不是新决策权规则**：47 条失败不是缺规则，是 Decision Authority 从来没有作用对象——欠定点不显形，「目标层归 Keith」就没有输入。空槽给既有规则造输入生产现场。
4. **grill flavor 处置**：保留 pull（本轮第二轮实证工具本身有效，一问即改判议题），修内部矛盾（删「不派 subagent」或改为允许派查证）；空槽给它递入口——欠定点多条且相互依赖时，方案文档里写一句「建议跑一轮拷问」，Keith 异步决定。触发从「Keith 记得喊」变成「产物把入口递到眼前」，不上 push 自动判定。
5. **轻任务象限不动**：无信号词且不走 Workflow 的轻任务维持既有裁定（直接做 + Keith 在场纠），不为 L4 残余建机制。
6. **tripwire**：槽实填率传感器 + 按 monster 准入造首个阳性；若槽实填但目标层失败率不降 → 按 dimension-blindness 换维度，本裁决可被结算证伪。

### 裁决三：与 D 段三次既有裁定 —— 补充，不推翻

三次裁定的内核（提醒型规则在轻任务帧恒失效 / Keith 在场兜底合理 / 不加提醒型新规则）全部保留。新增的是它们当时没有的两个事实打开的第三条路：47 条分层统计 + 约束 4（2026-08-17 才立的样板杠杆）。本裁决走的既不是「提醒」也不是「新机制」，是产物骨架结构——三次裁定否决的选项集合里没有这一项。2026-08-05 提案按「真空口真实、形态否决、以空槽形态收口」处置，夜巡标注关闭。

### 诚实边界

「欠定点空槽降低目标层失败率」无直接实证，是可结算预测（判据见开题②）；判定仍在 LLM 手里，这不是飞轮——但按 mechanical-gate（语义模式无机器可判物理量），产物锚已是当前可达最强形态。

## 元属性反思

**核心假设**：① 押「结构动作 vs 姿态动作」的实测二分可迁移到「欠定点空槽 vs 复述回显」——外部实证（falsification-as-structure）+ gg 自身 opening-protocol 运行经验 + PRD 骨架 7/9 三源同向，但无本场景直测。② 「意图回显已做仍偏（2026-06-29）」被我归因为镜像动作固有缺陷——若真因是能力层（复杂需求本质欠定），空槽同样收不动，会在 tripwire 现形。

**可能出错的地方**：monster 是否存在统一的「方案 / brief 模板」骨架供空槽安家——实现层细节我未核实；若无统一模板，落点退为 CLAUDE.md「意图回显」段的字段升级（在场性打折但内核不变）。

**推理盲区**：47 条样本的分层是父会话做的，我采信其归类；若①目标层 22 条里混有大量「问了也没用」型，L4 残余占比上修，机制收益下修——tripwire 是补这个洞的机制。

**根因预判**：本议题拖了 16 个月（grill 零使用）+ 13 天（08-05 提案未落地）的深因：所有候选形态都在「触发」轴上打转（pull vs push vs 默认态），而病在「产物」轴——帧内提不出的问题，换任何触发都提不出，只有把它变成填不出就交不了差的字段。

**北极星触达**：决策超越直觉（depth）——把「该不该问」重写为「欠定性住在哪」；二阶效应（space）——空槽同时给 Decision Authority 造输入、给 grill 造入口、给 tripwire 造靶，一石三鸟。

**essence 对齐自检**：`frame-grammar`（换帧不加提醒，直接消费）✓；`falsification-as-structure-not-just-skepticism`（软怀疑无效 → 否决讨论态姿态规则）✓；`field-gravity-over-prompt` / `reverse-anchor-by-reflection`（产物锚机制）✓；`anchor-value-in-activation-not-in-content`（grill 内容在、激活缺；修激活不重写内容）✓；`retiring-a-dead-mechanism-orphans-no-one-who-lives-elsewhere`（要求元动作的机制没活过——同判例直接引用）✓；`mechanical-gate-needs-machine-detectable-target`（不上 L3 hook，语义判定回 L1/样板层）✓；`dormant-rule-first-light-is-a-retrial-not-a-debt-call`（16 个月哑火 → 重审形态而非催债加压）✓。反向打我的滴：`engineering-impulse-as-load-bearing-disguise`——committed 消费方存在吗？存在：Decision Authority 分流规则就是空槽的既有消费方，非调研背书。`separation-need-is-not-topology-verdict`——是否先试了最轻形态？是：改已有强制动作的产物模板，不建新墙。对齐度：高。
