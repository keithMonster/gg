# Reflection: 会议纪要归属——粒度保真转写，不是豁免

### 给父会话的最终输出（必填）

**裁决 1：进。** 会议纪要不是「缺归属」体裁，是「归属模态不同」体裁——正文 roster 本身就是具名人集合，具名 participant 契约在物理上已可满足；缺的不是 ENTITY_KINDS 的 unknown/meeting，是 **role/模态词表**（无法表达「这些具名人组成的决议体得出 X」区别于「此人做了 X」）。冲突真身 = essence #171 hard-rule-weld：意图（可审计归属）与形态（具名个人主语）焊在同一硬约束里，纪要是第一个合法偏离者（过意图、违形态）；正解 = 拆焊——意图留硬、形态扩为受控模态集。且这 1/5 语料是组织决议层事实，是组织世界模型的心脏而非边角料，挡在外面 = 只记个人动作不记组织决定，价值倒挂。

**裁决 2：归属判据 = 「转写源文本明示的归属，粒度不变」不变量 + 双向禁令**：禁上折（集体结论按到具名个人含记录人 = 伪精度）、禁下折（有具名 roster 的扔 blocked = 伪缺失）。机械瀑布（逐条 assertion 判，不逐文档）：
- **T1** 结论句语法主语 = 名册可解析人名 → person + 行为 role（现行路径）
- **T2** 集体/无主语 + 正文有明示参会名单 → roster 全体 person（role=决议体成员，新模态）+ 记录人（role=记录人）；roster 部分解析必须显式完整性标记，禁静默降为子集
- **T3** 无 roster → 仅记录人（role=记录人）+ 会议级粒度标记；谓词必须是集体模态（语义主语=会议），防记录人被读成发言人
- **T4** 职能模糊指代（「相关负责人（销售）」）→ 不解析为人，指代原文留 qualifier；若该指代是必要主语且无 T1-T3 支撑 → blocked「归属粒度不足」。名册无此人 → 现行 blocked 路径不变
- 附则：roster 只认正文明示参会名单，**禁用 receivers/deptId 代位**（父会话已实证两者不一致）；role=决议体成员语义 = 在场成员≠背书者，查询展示层不得把决议体命中折叠成个人行为命中。

**契约动作（一次性，须过冻结变更闸）**：扩 role/模态词表（决议体成员/记录人）+ 若干集体模态谓词。模态集按**归属模态**定义（个人行为/决议体/记录），封闭小集合，不按体裁定义——不构成逐体裁开洞先例（ontology-expansion cap）。**明确 reject 三路**：① 注册 meeting/event 实体（8K 一次性事件实体灌名册；evidence locator 已唯一标识那场会，重复建模）② attribution_caveat 扩权为豁免通道（RUNBOOK:443 自己已禁 qualifier 打补丁，上折伪精度正是它标注的病）③ 另立「决议账本」分层（砍断人/项目时间线跨两类事实可比性，七闸机器全套重复）。

**裁决 3（不进分支）**：不成立。blocked 是待决队列不是体裁归宿，8K 条以「归属粒度不足」长驻 = 把 blocked 变影子账本，比进/不进都糟。

**裁决 4（最可疑点，进冻结闸前必测）**：T2 的承重经验前提是「roster 在正文普遍存在且可解析」，而父会话完整实读 n=1（陈尚书一篇）。分层抽样 ≥10 作者 × ~50 篇，测 ① roster 在场率 ② roster 人名对名册解析率。在场率低 → 体裁主通道塌到 T3（仍进，但人级查询价值大缩水，冻结闸变更的重心要改为集体谓词而非 roster role）。次可疑：perspective.mode=meeting 的派生依据若是标签非内容，可能混入非纪要——但 perspective 订正成本极低，不承重。110/148 的 grep 口径数会被抽样直接取代，不必单独复核。

### 核心假设

### 可能出错的地方
