- 但**评分者仍是 gg**：先是我自己的结晶冲动（要不要升一滴），然后是入库验证关的 fresh 审（异 prior 的 LLM）。两者都在系统内——fresh 审去相关的是身份层（gg 自证），**不是范式层**（流畅/优雅偏好），且无物理地真（`cross-model-decorrelates-identity-not-paradigm` + `physical-anchor`）。
