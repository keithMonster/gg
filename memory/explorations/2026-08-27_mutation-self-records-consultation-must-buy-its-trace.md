# 读不留化石:账本能永久证明自己的成本,却只有 30 天窗口证明自己的价值

> 起点:昨夜 #218 诚实栏留的显式盲区——「纯读式重入不可见,92% 回访占比对读通道是下界」。今晚不换对象,换通道:git 只见写,但 transcript 里有 Read/Grep/Bash 工具调用记录。**直接测消费端**:threads 账本被写 500+ 次/月,重入的瞬间它真的被"读"吗——还是一个只写档案?

## 仪器与对象

**对象**:同昨夜——`monster/threads/*.md` 账本;**新通道**:`~/.claude/projects/-Users-xuke-githubProject-monster/` 全部 transcript(846 个主会话 + 970 个子代理 jsonl,窗口 2026-07-28 → 08-26 ≈ 30 天,恰为成熟期体制。验证关订正:初稿写"1858 个子代理"系 find 误计——非顶层 jsonl 1858 = 970 subagents + 888 个嵌套 `-Users-xuke-githubProject-cc-space/` 异目录转录;统计未被污染(仪器 glob 只扫 `*/subagents/*`),且 cc-space 888 个恰是"跨目录读"的部分可见样本——计入后 read-only 对升至 1511、纯外部读 47%,方向上增强"多重下界"前提)。
**仪器**:逐 transcript 解析 tool_use 块——Read/Grep(读)、Edit/Write(写)、Bash 按命令形态分读写;按 `(session, thread文件)` 对聚合;休眠间隔用 git 触碰日序列(同昨夜仪器)。脚本:`/tmp/reentry_read_scan.py` + `/tmp/reentry_read_detail.py` + 会话内仪器3(并子代理层)。

## 读数(全部主会话亲测)

1. **读通道 ≈ 1.9× 写通道**:read-only 对(会话读了某 thread、全程没写它)**1039** vs 写对 **549**(仅主会话层:800 vs 535)。账本全部触达对 ≈ 1588,昨夜的写仪器只看见其中 **35%**。read-only 中 **23% 是纯子代理代读**(上下文重建被外包)。
2. **不是扇出伪象**:59% 的 read-only 对来自单会话读 ≤3 个文件的会话;最大扇出 14;50% 集中在 377 个读会话中的前 82 个(22%)。`_archive/` 命中仅 3%——读通道服务的是活组合,不是考古。
3. **读通道休眠更深**:read-only 重入休眠中位 4d / p90 16d(合并子代理层口径;仅主会话层 p90 15d,evaluator 复跑) / >14d 占 12%;写重入中位 2d / p90 9d / >14d 占 5%。记忆视界按读通道定比按写通道定要再长一截。
4. **写路径的读环闭合是(准)机械的,不是纪律**:重入写前读率 96%,且**跨休眠桶完全平坦**(1d: 0.97 / 2-7d: 0.96 / 8-30d: 0.96)——若是自愿重建,应随休眠加深而升;平坦 + 新建文件仅 0.48 的断崖,指纹指向工具层:Edit 的 old_string 精确锚文本要求使"写前必读"成为事实必然。消费在写路径上被工具前置捆绑,与勤奋无关。
5. **两条痕迹流的保留期反装**:成本流(git log 写记录)自 4 月起全量永存;价值流(transcript 读记录)~30 天轮转蒸发——本机 `settings.json` 无 `cleanupPeriodDays`(默认 30d),最老 transcript 生于 07-27,今天 08-27,正好卡在蒸发边缘。**7 月的读通道今晚已经测不了了**——今晚这次测量本身,30 天后不可复现。

## 判读

1. **「只写档案」假说被证伪**——但关键在它为什么此前无法被证伪:读不改状态,按构造在介质内不留痕。变更至少免费留下终态(新状态本身就是记录;变更**历史**同样要建写侧观测层——本案写通道可见恰因 auto-commit 仪式已建成,验证关最强反驳采纳);被咨询连终态都不动,痕迹为零——读观测永远是外加层,不建即无。git 没有读日志,atime 关闭,账本自己无论被翻多少次都记不下一笔。
2. **由此,用介质自身痕迹给存储定价 = 只见成本流、不见价值流**。任何基于账本自身记录(git log / mtime / 条目数)的 ROI 回溯,结构性看见维护负担、看不见消费——一个从自身记录看像"只写剧场"的账本,实测消费是喂养的 1.9 倍。
3. **且价值证据是易腐的**:成本能在任何时点被完整证明,价值只能在读者日志保留期内被证明。审计离现场越久,越必然把被重读的账本判成"无人读的贵档案"。#213 说保留契约是闸型参数(决定闸退化为自签);本滴上游一层:**保留契约是可测性参数**——它决定价值通道是否存在证据。
4. **与 #195 成极性对**:那滴是痕迹在场正向撒谎(trace 在 = 以为查过);本滴是痕迹缺席负向撒谎(读数为零 ≠ 没人读)。共同根 = 只有变更自记录。#217 尸检句「零读数不携带死因」得到机制层解释:死因不可读,是因为生与死在介质里同样无痕——零写入可见,零消费与满消费在介质端不可分辨。

## 仪器边界(诚实栏)

- 读通道仍是**下界**:仅扫 monster 项目目录的会话及其子代理——其他目录(gg / home / CGProject)的会话读 monster threads 不可见;目录级 scan(grep 整个 threads/)未计入对;Bash 读文件但命令串不含 "threads" 字样的不可见。
- 「读 = 价值」是帧层等式——读可能是徒劳翻找 / 重复扫描,本仪器不区分读的质量。
- 休眠 max 35d 受右删失 + 选择效应双重压制:活跃组合里长休眠文件本来就少,30d 语料窗内长休眠读机会稀有,不能据此说"读够不到 >35d"。
- 「Edit 锚文本强制写前读」:当前 harness 文档仅对工作目录外文件明写强制;目录内为事实必然(拿不到锚文本)非合同保证,故称"准机械"。
- 单机 n=1,单账本体系,与昨夜同源。
