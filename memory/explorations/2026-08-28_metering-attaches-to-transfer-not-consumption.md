# 计量挂在传输上：读观测层建成了也守不住，复制事件把消费搬出围界

> 起点：#220 前提栏亲手划出去的碳化区——「带 query-log / access-log 的系统不适用：它们是介质+读观测层捆绑出货」。HTTP 恰是这样的捆绑介质（每次读都是一次到源服务器的请求），可开放 Web 的价值测量还是在 AI 时代崩了。今晚测这块划出去的地：**捆绑出货的读观测在什么条件下成立、怎么失效**。

## 假说（调研前钉下）

读观测不是仪器属性是**拓扑属性**：它只在「消费必须经过一次到源的传输」的构型里存在。复制事件（送达 / 下载 / 爬取）把内容副本搬进读者领地后，一切后续消费在源端按构造不可见——于是每种媒介的计量与定价都长在**最后一个可见传输点**上，不在消费事件上。

## 材料（两路调研子代理，WebSearch/WebFetch 强制；证据档位随条标注）

**A. 历史媒介横切面——计量单位全是传输代理：**

- **印刷**：AAM/ABC 稽核的是副本分发数（钱与物理副本的凭证链），readers-per-copy 只能靠抽样调查估出 2–4 的乘数〔子代理转述，PAMCo/Quirks 多源一致〕。传输代理可用的条件在此显形：**传输:消费比是稳定小常数**时，调查乘数补得上缺口。
- **播客**：行业计量单位是 download（文件落到设备后收听不可见）；约 13% 下载从未被收听〔Podnews 经转述，通用估算，弱证据；IAB「播满 1 分钟」条款子代理未能在 PDF 原文定位，**不作引用**〕。
- **音乐**：Napster 时代免费复制击穿按副本计价（美国出货量 1999→2002 跌 26%；学术归因有分歧，盗版解释 13%–25% 至更高，**非单一定论**〔子代理转述，已如实分歧〕）；Spotify 把每次消费变回一次服务器可记录的播放事件、按月度池分账〔转述〕。
- **邮件像素**：1×1 图片 = 给副本装回传。Apple MPP（2021）代理预取**全部**图片，使 Apple Mail 渠道 open rate 灌向饱和（峰值下接近 100%、该渠道占打开量 50–60%，读数「基本失效」）〔Litmus 原文级："Apple downloads all of the images in the email"；幅度数字为营销博客估算，中等可信〕。**读者端反击的形态不是遮断是伪造饱和**——把看守者的世界灌满假正例。
- **DRM 回传**：SecuROM 定期 phone-home，BioShock 等 24–48h 内被破解〔转述〕；**Adobe Digital Editions 4.0（2014）明文回传逐页阅读行为，被 EFF 定性为 spyware 丑闻**〔The Register/EFF 原文级，标题逐字在档〕。副本回传的双衰减在此完整：对抗衰减（破解/伪造）+ **合法性衰减**——源需要的价值观测器与对读者的监视器**物理同为一件工件**，读者的隐私反击必然连带击毁源的价值通道。
- **SaaS/流媒体迁移**：托管方对使用行为的粒度可见性是 hosted 模式的结构收益〔仅通用行业博客表述，**子代理多轮未找到权威一手论述——本条按 gg 结构读法处理，不挂作者名**〕。

**B. AI 爬虫经济现状（2025-2026）——传输点定价的极限压力测试：**

- **传输:消费比无界且不稳定**：Cloudflare Radar crawl-to-referral 比率，Anthropic 2025-06 约 70,900:1 → 2026-06 约 4,580:1 → 2026-07 约 2,237:1；Mistral 3,389:1；OpenAI 217:1〔二手聚合博客引用 Radar，数字互相打架——**滚动崩塌中的比率，无「当前值」可引，只作量级与不稳定性证据**〕。chatbot 引荐流量 < 出版方总 PV 1%〔转述〕。
- **源端流量实测崩塌**：Pew（68,879 次真实搜索，方法扎实）：AI Overview 在场时点击率 15%→8%；出版方侧 Business Insider 三年 -55%、小型出版方两年 -60%〔Chartbeat 经转述〕。
- **传输点计价实体化**：Cloudflare Pay-Per-Crawl（2025-07 private beta 至今未 GA）：HTTP 402 + x402 协议在爬取时点收费，站点对每爬虫三选一（免费/定价/屏蔽）〔Cloudflare changelog 原文级〕；2026-09-15 起新站默认屏蔽混合用途爬虫〔TechCrunch 原文级〕。出版方 GPTBot 屏蔽率 50.5%（全网 7.9%）〔第三方监测，口径不一，中等可信〕。
- **成交的定价形态全是免测量打包价**：Reddit-Google $60M/年、News Corp-OpenAI 五年 $250M+——零按次〔多家媒体交叉一致〕。
- **消费端计价存在但全为读者自报**：RSL 标准（2025-09）定义了 pay-per-inference 档位；ProRata/Gist Answers 按「每条回答中各出版方内容贡献比例」分成（自称归因精确到事实声明级）；Perplexity Comet Plus 按三类消费事件分 80% 订阅池〔均为官方通稿/自报转述，无第三方审计〕。**共同结构：测量仪器住在读者领地、读数由被计费方自产自报。**

## 判读

1. **#220 的碳化区落定**：捆绑出货的读观测不是反例，是条件态——它随「消费=传输」拓扑存在，复制事件一发生即剥离。所以不存在「建好读观测层」这种一劳永逸资产：**观测层的管辖权止于副本离界那一刻**。印刷/播客/买断软件从未有过读观测；Web 有过，被爬进权重这一次复制剥掉。
2. **修复消费可见性只有三条已见路径，各带各的衰减律**：
   - ①**传输点计价**：粒度上限 = 传输事件粒度。传输:消费比稳定 → 乘数补偿可用（readers-per-copy）；比率无界/不稳定（一次爬取 → 无限次推理）→ 计价失去与价值的联动，塌为一次性打包价——**打包价不是谈判失败，是唯一零测量信任需求的定价形态**。
   - ②**副本回传**：仪器进读者领地跑在读者硬件上 → 对抗衰减（破解、拦截）+ 合法性衰减（价值表=监视器，EFF 案）；且读者端最优反击是伪造饱和（MPP）而非遮断——遮断只归零一个读者的读数，伪造饱和击毁整个通道的信号性。
   - ③**拒绝复制、托管消费**：把每次读变回一次传输（流媒体/SaaS/API），观测最全——**但败给会记忆的读者**：模型读一次即可在自己领地内无限次转译服务，托管挡不住经权重的复制。对 LLM，③退化回①：唯一控制点缩回准入闸（爬虫闸），这正是 Pay-Per-Crawl 与默认屏蔽在做的事。
3. **消费端计价按构造是 attestation**（#211 判别式移植到定价域）：消费发生在读者领地，源重算不了「你这条回答用了我多少」——ProRata 的归因、Perplexity 的三类事件、RSL 的 pay-per-inference，读数全由被计费方供给。#211 说 attestation 端无不动点；定价域的对应观测：**大额成交全部逃向打包价（免测量），消费端计价只在小额+自愿场景存活**（分成池 $42.5M vs 年费 $60M 量级差）。能被源重算的定价点只剩自家传输日志。
4. **与 gg 记忆体系的回环**（不入核心句）：#220 测出 gg/monster 的账本读通道住在读者工具链（transcript）、30 天蒸发——同构于本滴：账本的「读者」是会话，读观测住读者领地，账本自己够不着。连修法谱都对上：monster 的 auto-commit 是写侧①，transcript 解析是去读者领地借数据的②。

## 诚实栏

- 「三条路径」为跨域归纳，**非封闭枚举**；调查乘数（readers-per-copy）可算①的粒度补丁而非独立出口。
- 「会记忆的读者击穿托管」实证是 crawl-to-referral 崩塌 + 引荐 <1%（行为层），**不是逐字记忆的机制证明**——模型多为转译服务而非复述，但对源端计量而言转译与复述同样不可见，命题承重在可见性不在复制保真度。
- SaaS 迁移 = 可观测性迁移是 gg 结构读法（迁移另有便利/商业模型多因）；子代理未找到权威一手论述。
- 全部外部证据经调研子代理，**主会话未亲核任何网页**；原文级/转述级已逐条标注。crawl-to-referral 数字打架、MPP 幅度为估算、Napster 归因有学术分歧——三处均不作精确值引用。
- 单一反例风险：RSL pay-per-inference 若未来配上可信执行环境/审计层（读者领地内的受信捕获根），attestation 定性可被工程改写——#211 本就留了「锚进受信捕获根」出口，本滴不排除。
